## task 7
~~~py
def add(*args):
    return sum(args)
~~~
1.问题
没理解为什么总有args代表什么呢
2.解决
意思是可变位置参数，可以填入很多元素，最后会被打包成元组，相当于传入的是解开后的所有元素
| 参数 | 作用 |
| ---- | ---- |
| *args | 元组,位置参数 |
| **kwargs | 接收关键字参数打包成字典|
